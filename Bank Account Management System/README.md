# Bank Account Management System

A simple Java Object-Oriented Programming (OOP) project that demonstrates encapsulation, validation, and basic banking operations.

---

## Features

- Create a bank account with Account Number, Account Holder Name, and Initial Balance
- Validate account details during account creation
- Deposit money into an account
- Withdraw money from an account
- Prevent invalid withdrawals
- Update account holder name with validation
- Access account details using getter methods

---

## Concepts Used

- Object-Oriented Programming (OOP)
- Encapsulation
- Constructors
- Getter and Setter Methods
- Input Validation
- Exception Handling
- Method Implementation

## How to Run

### Compile the Project

```bash
javac BankAccount.java BankAccountDemo.java
```

### Run the Program

```bash
java BankAccountDemo
```
