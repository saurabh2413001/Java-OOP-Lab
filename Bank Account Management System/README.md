Bank Account Management System
A simple Java Object-Oriented Programming (OOP) project that demonstrates encapsulation, validation, and basic banking operations.

Features
Create a bank account with Account Number, Account Holder Name, and Initial Balance.
Validate account details during account creation.
Deposit money into an account.
Withdraw money from an account.
Prevent invalid withdrawals.
Update account holder name with validation.
Access account details using getter methods.
Concepts Used
Object-Oriented Programming (OOP)
Encapsulation
Constructors
Getter and Setter Methods
Input Validation
Exception Handling
Method Implementation
Project Structure
BankAccountManagementSystem/ ├── BankAccount.java └── BankAccountDemo.java

Sample Output
Account Number: ACC101 Account Holder: Aman Initial Balance: 5000.0

Deposit Successful: true Balance After Deposit: 6500.0

Withdrawal Successful: true Balance After Withdrawal: 4500.0

Invalid Withdrawal Successful: false Final Balance: 4500.0

How to Run
Compile the project:

javac BankAccount.java BankAccountDemo.java

Run the program:

java BankAccountDemo

Learning Outcomes
Understand encapsulation using private fields.
Implement constructors and validation logic.
Develop banking transaction operations.
Build reusable and maintainable Java classes.
Strengthen Object-Oriented Programming fundamentals.
