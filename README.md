# Java OOP Lab

A collection of Java Object-Oriented Programming (OOP) lab projects developed to practice and demonstrate core OOP concepts such as encapsulation, inheritance, abstraction, polymorphism, constructors, method overriding, validation, and exception handling.

---

## Projects

### 1. Bank Account Management System

A simple banking application that allows:

- Account creation with validation
- Deposits and withdrawals
- Balance management
- Account holder updates
- Encapsulation using private fields

**Concepts Used:**

- Classes and Objects
- Encapsulation
- Constructors
- Getter and Setter Methods
- Validation
- Exception Handling

---

### 2. Employee Management System

A payroll management system supporting multiple employee types:

- Full-Time Employees
- Sales Employees
- Bonus Calculation
- Commission Calculation
- Salary Computation Using Polymorphism

**Concepts Used:**

- Inheritance
- Method Overriding
- Polymorphism
- Encapsulation
- Constructors
- Input Validation

---

### 3. Payment Processing System

A payment processing application that demonstrates abstraction and runtime polymorphism through multiple payment methods.

**Features:**

- Credit Card Payment Processing
- UPI Payment Processing
- Abstract Payment Class
- Runtime Polymorphism
- Input Validation
- Exception Handling

**Concepts Used:**

- Abstraction
- Abstract Classes
- Abstract Methods
- Inheritance
- Method Overriding
- Runtime Polymorphism
- Encapsulation
- Constructors
- Exception Handling
- Input Validation
