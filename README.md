# Java OOP Lab

A collection of Java Object-Oriented Programming (OOP) projects developed to practice and demonstrate core software engineering and object-oriented design principles.

This repository contains hands-on implementations of real-world systems that strengthen concepts such as encapsulation, inheritance, abstraction, polymorphism, validation, exception handling, composition, and business logic design.

---

## Projects

### 1. Bank Account Management System

A simple banking application that provides secure account management functionality.

**Features**

- Account creation with validation
- Deposit and withdrawal operations
- Balance management
- Account holder information updates
- Exception handling for invalid operations

**Concepts Used**

- Classes and Objects
- Encapsulation
- Constructors
- Getter and Setter Methods
- Validation
- Exception Handling

**Concepts Used**

### 3. Payment Processing System

**Features**

- Exception Handling

**Concepts Used**

- Inheritance
- Method Overriding
- Runtime Polymorphism
- Encapsulation
- Constructors
- Validation

---

### 4. Food Order Processing System

A complete food ordering and billing system that validates customer orders, calculates bills, applies discounts, manages delivery charges, and generates detailed receipts.

**Features**

- Order Validation
- Customer Information Validation
- Item Validation
- Discount Calculation
- Delivery Fee Management
- Receipt Generation
- Bill Computation
- Exception Handling

**Business Rules**

- 10% discount on orders above ₹1000
- Free delivery on orders above ₹500
- Delivery fee of ₹40 otherwise
- Automatic bill generation with rounded monetary values

**Concepts Used**

- Classes and Objects
- Encapsulation
- Composition
- Collections Framework (`List`)
- Validation
- Exception Handling
- Business Logic Design
- Immutable Data Structures
- Separation of Concerns
- StringBuilder
