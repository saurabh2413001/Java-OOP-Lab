Java OOP Lab
A collection of Java Object-Oriented Programming (OOP) lab projects developed to practice and demonstrate core OOP concepts such as encapsulation, inheritance, polymorphism, constructors, method overriding, validation, and exception handling.

Projects
1. Bank Account Management System
A simple banking application that allows:

Account creation with validation
Deposits and withdrawals
Balance management
Account holder updates
Encapsulation using private fields
Concepts Used:

Classes and Objects
Encapsulation
Constructors
Getter and Setter Methods
Validation
Exception Handling


2. Employee Management System

A payroll management system supporting multiple employee types:

Full-Time Employees
Sales Employees
Bonus Calculation
Commission Calculation
Salary Computation Using Polymorphism
Concepts Used:

Inheritance
Method Overriding
Polymorphism
Encapsulation
Constructors
Input Validation
